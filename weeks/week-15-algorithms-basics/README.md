## 知识点速记
- 排序：`O(n²)` 冒泡/选择/插入；`O(n log n)` 快排/归并/堆排
- 查找：顺序 `O(n)`、二分 `O(log n)`（前提：已排序）
- **大 O 表示法**描述的是"数据量翻倍时，耗时大概翻几倍"
